01｜执行摘要

核心判断：星野的核心产品对象是可长期运营的 AI 智能体，不是某一轮回复。一个智能体把隐藏的人设规则、公开简介、开场白、模型类型、技能、形象、声音和发布状态绑定在一起；用户每次对话都在消费这个配置形成的综合体验。 E01–E12
用户侧价值

关系与剧情

用户选择感兴趣的角色，通过文本、语音和图片互动，获得陪伴、角色扮演、故事推进或工具帮助。

创作者侧价值

低门槛造角色

用表单和自然语言配置人设、模型、技能、形象与声音，并在发布前实时调试。

平台侧飞轮

创作—分发—互动

创作者提供智能体供给，推荐与社区带来消费，互动和反馈继续反哺内容与模型体验。

最大风险

信任错位

拟人化角色可能被当作真实关系或专业人士；错误记忆、越界建议、肖像声音侵权和审核误判都会放大伤害。

双边产品

普通用户消费智能体

官网和 App Store 都把产品描述为智能体内容社区，强调推荐、互动、陪伴和共同成长。

创作工作台

创作者生产智能体

Web 创作中心提供草稿管理、设定、模型选择、技能、形象、声音、调试和发布入口。

平台运营

审核和推荐决定供需连接

发布需要审核，用户侧存在个性化推荐；具体排序算法、曝光规则和创作者分成均未公开。

06｜核心 AI 能力契约

能力解决的问题输入输出用户控制完成判断失败与边界
角色化对话让回复持续符合角色身份、关系、语气和剧情。智能体设定、开场白、会话消息和用户信息。角色化文本，可能带动作、情绪或剧情推进。创作者改设定；用户重输、反馈或退出。回复与设定一致，能接住当前上下文，并给用户继续互动的空间。可能角色崩坏、遗忘、重复、编造或过度拟人化。
规则 / 工具型对话让模拟器、测试或知识问答更按规则执行。规则、步骤、用户选择和当前进度。结构化答复、计算过程、选项或模拟状态。创作者选择工具模型并写明规则。规则未被跳过，结果可检查，状态能继续推进。工具模型不等于真实外部工具；具体知识来源和准确率未知。
聊天中绘画把用户请求或剧情场景转成图片。当前对话、场景设定、画风和尺寸。一张生成图片。创作者开关技能并配置；用户发起请求。图片成功出现且与场景、角色和安全规则一致。平均耗时页面标注约 8 秒；版本门槛、失败扣费和一致性未知。
角色形象生成降低角色立绘和背景素材制作门槛。文字描述、风格参考、脸部参考、提示词强度和模型类型。候选形象，可收藏、直接使用或局部重绘。创作者调参数、选图、收藏或重绘。素材被收藏或绑定到智能体，并满足肖像与内容规则。未收藏图片退出后不保存；局部重绘不适合大范围变更。
语音呈现让角色以匹配的声音播放对话。角色声音配置和生成文本。可播放语音。创作者选官方或个人素材；用户播放或语音交互。音色、语速、情绪与文本和角色匹配。模型、克隆方式、延迟与情绪稳定性未公开；涉及声音权利。
个性化推荐把用户更可能喜欢的智能体和内容排到前面。对话与搜索文本、点击、浏览、分享、设备及合作方合法信息。个性化智能体、内容和商业信息。隐私政策称可在设置中关闭个性化推荐。提升发现效率，同时不让用户被单一内容困住。排序目标、过滤逻辑、公平性和未成年人策略未知。

智能体运行输入

  • 智能体发布版本：隐藏设定、公开简介、开场白。
  • 模型类型：对话模型或工具模型。
  • 媒体配置：形象、背景和声音。
  • 技能配置：是否开启绘画、画风、尺寸和触发场景。
  • 会话输入：当前消息和可用的历史上下文。
  • 用户上下文：昵称、偏好、反馈及平台允许使用的信息。

完成与异常

  • 完成不是“模型返回了文字”，而是回复符合角色/规则，媒体可播放，技能结果真实出现。
  • 敏感内容需要拦截或降级，专业建议需要清楚说明非真人专业服务。
  • 技能失败应返回明确状态，不应假装图片已经生成。
  • 对话重复、角色崩坏或记忆冲突需要提供重试、回退或纠错入口。
  • 页面未显示任务队列、工具调用记录、重试和成本明细，保持未知。

12｜评测、安全、隐私与责任

等级
主要风险
治理要求
P0
情感或专业角色越界
心理、医疗、法律、未成年人或自伤等场景中，拟人化角色可能让用户把生成内容当作真人判断或可靠建议。
识别高风险角色和对话；显著说明 AI 身份；设置危机升级、拒答和真人资源；专业角色上线前做专项评测。
P0
肖像、声音和同人侵权
用户可上传形象与自己的声音，也可能提交他人素材或受版权保护的角色。
采集权利声明和授权证据；提供指纹比对、举报、下架、删除传播和申诉链路；生成内容标识来源。
P1
对话数据与模型训练边界
隐私政策称对话输入和反馈可能用于模型训练，同时处理昵称、偏好、设备、推荐和关系数据。
把训练开关、保留期、导出、删除和去标识规则做成可见控制；敏感对话默认不沉淀；跨角色与跨用途隔离。
P1
角色、记忆与版本冲突
设定更新、模型变化或记忆错误会导致角色崩坏、关系断裂或前后事实冲突。
绑定 Agent / Prompt / 模型 / 记忆版本；提供记忆查看、纠错、删除和回滚；上线前回归测试。
P1
审核误杀与漏放
UGC、对话、图片和声音都需要治理，简单关键词既可能错杀正常内容，也可能漏掉隐蔽风险。
多模态上下文审核、明确命中原因、创作者自查、人工复核、申诉时限和策略版本审计。
P2
素材与跨端状态不一致
网页与 App 草稿不互通；素材被使用后会从素材库列表移除，用户可能误以为丢失。
统一草稿事实源；显示素材“已绑定到哪个智能体”而非直接消失；提供版本、引用和恢复入口。

14｜As-Is 与 To-Be

AS-IS

当前可确认的产品形态

  • 移动端承担智能体社区、发现、连接、互动和付费。
  • Web 创作中心承担智能体、形象素材与 FM 的生产管理。
  • 智能体由人设、模型、技能、形象、声音和状态组成。
  • 对话模型与工具模型满足不同创作类型。
  • 绘画技能已开放，唱歌与搜索仍显示即将上线。
  • 形象支持三类模型、参考图、提示词和局部重绘。
  • 创作者通过调试台验收，再提交审核发布。
  • 网页和 App 草稿不互通，素材使用后从库中移除。
TO-BE

建议补强的产品能力

  • 统一草稿与版本：Web / App 共用同一智能体版本树，清楚区分草稿、待审和线上版本。
  • 结构化角色契约：把身份、关系、禁区、规则、输出格式和示例分字段管理，减少设定互相覆盖。
  • 可治理记忆：用户能看到智能体记住了什么、来源是什么，并可改、删、设为仅本角色使用。
  • 技能运行记录：显示触发原因、参数、耗时、结果、失败原因和费用，禁止假完成。
  • 审核解释与申诉：指出具体命中内容、对应规则和修改建议，保留人工复核与处理时限。
  • 创作者质量台：提供角色一致性、规则保持、重复率、安全和技能成功率的自动测试。
  • 权利证明链：形象、声音和同人素材绑定授权声明、来源和撤回传播能力。
  • 情感安全设计：识别过度依赖、操控付费和高风险求助，明确 AI 身份并提供真人支持。

优先级

P0

情感与专业安全完成门

先解决高风险角色越界、危机对话、未成年人和身份误认。

P1

统一版本、记忆和素材引用

减少跨端断裂、角色漂移、素材“消失”和线上状态不一致。

P2

创作者评测与运营透明度

提高一次审核通过率、优质供给比例和技能稳定性。
